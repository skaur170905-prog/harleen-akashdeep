# Harleen & Akashdeep — Interactive Engagement Invitation

A mobile-friendly GitHub Pages invitation with:
- Pink envelope opening animation
- H + A wax seal
- Your supplied invitation artwork
- Quiet floating/flying birds
- Gentle botanical motion
- No frameworks or build tools required

## Files
- `index.html` — page structure
- `style.css` — all design and animation
- `script.js` — opening/closing interaction
- `assets/invite.jpg` — supplied invitation artwork

## GitHub Pages
Create a new GitHub repository, upload all files while preserving the `assets` folder, then:
1. Open the repository's **Settings**
2. Open **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Choose branch **main** and folder **/ (root)**
5. Click **Save**
6. Wait for the Pages deployment to finish
7. Open the generated `github.io` address

The site is static, so there is no server or database to set up.
